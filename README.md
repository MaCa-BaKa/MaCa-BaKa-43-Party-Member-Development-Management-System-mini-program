# 43-党员发展管理系统(小程序)

[文档地址](http://wechat.zjrcsy.cn/)

##### 技术栈: springBoot+Vue+Mysql+Uni-app 

##### 功能点: 用户端   管理员端 (ruoyi框架)



##### 用户端: 

1.首页: 轮播图展示、展示党建文章列表, 可进行点击查看文章详情

2.工作台: 展示当前阶段身份, 以及发展流程展示图、 资料申请入口、党课结业证书上传

3.材料模板:  共22个模板可进行下载: 入党申请书、入党积极分子思想汇报、政治审查材料等以及使用说明

4.我的: 

个人信息展示及修改

系统消息提醒

接收通知通知

操作手册以及常见问题



##### 管理员端: 

1.首页: 查看党员用户数量、材料模板、党建文章数量、通知公告消息、发展阶段echars展示图、发展流程图等

2.系统管理: 包含用户、角色、菜单、字典、日志管理模块,可进行具体的增删改查操作

3.党员管理: 展示党员列表,可进行操作

4.发展流程管理: 包含入党积极分子申请、发展对象申请、预备党员申请、正式党员转正等,各模块可进行具体的详情查看

5.党员材料管理: 党员材料模板(可对模板进行修改和删除)

6.党课结业证书: 查看详情

7.轮播图管理: 修改和删除

8.党建文章管理: 可修改和删除

9.消息: 可发布系统提醒与通知
